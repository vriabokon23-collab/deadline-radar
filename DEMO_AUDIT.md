## Fixes

- Preserve edited review rows across page navigation, even when Streamlit removes
  the hidden editor's widget state.
- Require correction or removal of unresolved placeholder deadlines before saving.
  Corrected dates retain the original extraction context with an updated note.
- Prevent another extraction while a review queue is pending, and require an
  explicit choice before saving duplicate module/title/date combinations.
- Show fixture/API mode in the sidebar and name offline fixtures in the extraction
  button; use neutral wording while preparing a plan.
- Distinguish an empty plan from suggestions that could not be matched, and replace
  advice to drop an assessment component with guidance to discuss priorities.

## Remaining rehearsal checks and limitations

- No Anthropic API key is configured in the shell or local dotenv environment.
  Live PDF reading, account/model access, latency and rate limits remain untested.
  The mocked API path exercises request construction and response validation;
  it does not demonstrate model extraction quality.
- Calendar bytes are generated by the actual sidebar export and parsed in tests.
  A real browser download and import into Google/Apple/Outlook still need manual
  rehearsal in a disposable calendar.
- AppTest verifies UI state and interactions, not rendered-browser layout or
  responsive appearance on the presentation display.
- Offline fixtures are synthetic and labelled; newly uploaded fixture deadlines
  never export. The 10 deliberately seeded demo assessments do export.
- Holiday deadlines retain the existing heatmap bucket limitation described in
  README.md. The reference date intentionally defaults to 16 October 2026.
